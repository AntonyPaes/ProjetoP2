# Pixel Top-down Town Tileset (16x16)
92 transparent PNGs: 11 ground, 10 road, 3 water, 12 roof, 6 wall tiles and 50 props (doors, windows, lamps, cars, market stalls, trees...).
Files: PNG/native (16x16), PNG/x4 (64x64), spritesheet.png/.json, tileset.png, sample_scene.png.
Engines: Unity, Godot, GameMaker - set Filter=Point (no filter), Compression=None.
